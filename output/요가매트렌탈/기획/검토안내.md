# 요가매트 렌탈 — 이미지 검토 및 최종 출력

검토용 장면 3장은 기존 공장 사진의 딥블루 투톤 외관을 참고해 OpenAI Image API (`gpt-image-2`, medium, 1536×1024)로 생성한다. 실제 행사·재고·보관 사진이 아닌 연출 장면이며, 별도의 사용자 승인 전까지 상세페이지에 삽입하지 않는다.

1. 행사장 세팅: 첫 화면의 서비스 소개
2. 기업 웰니스: 사내 프로그램 활용 예시
3. 스튜디오: 워크숍 시 매트 추가 준비 예시

사용자가 각 장면을 검토해 사용 가능 여부·수정 사항을 알려준 뒤 `이미지검토.json`에 그 응답의 근거를 기록한다. 도구 실행 성공이나 자동 품질 검사는 사용자 승인을 대신하지 않는다.

최종 레이아웃은 `출력계획.json`의 7개 주제로 구성한다. 각 JPEG는 가로 860px, 세로 1200~3000px로 내보내며, 카페24 HTML과 같은 순서로 배치한다. 이미지 원본 크기는 1536×1024이고 최종 상세페이지의 JPEG 규격과 별개다.

실제 재고의 두께(기존 문서 5mm/6mm 상충), 색상 선택 범위, 세척·포장 방식은 사용자 확인이 필요하다. 위생 증거·치수 측정·정확한 컬러칩을 AI 생성으로 대체하지 않는다.
