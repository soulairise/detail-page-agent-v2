# 공개용 상세페이지 제작 플레이북

실제 업무 플레이북에서 공급처·매입단가·검색량·거래처 정보는 공개본에서 제외했다. 아래는 동작 확인에 필요한 공개용 규칙 요약이다.

- 사용자에게 상품명·판매 유형·확정 사양·타겟을 받는다. 없는 수치·후기·판매량을 만들지 않는다.
- 포지셔닝과 스토리보드, 유료 생성 이미지, 최종 결과물은 사용자가 확인한다.
- 조사 도구가 실패하면 시장 근거 미확보로 기록한다.
- 의료 효능·질병명을 일반 용품 카피에 사용하지 않는다. rules.json 검사는 정규식·키워드 검사이며 법률 적합성 보증이 아니다.
- 고시·렌탈 조건은 실제 제공 제품과 확정 계약에 근거해야 한다. 모르는 값은 임의로 채우지 않는다.
- AI 장면 이미지는 활용 예시로 구분하고 실제 납품·색상·두께·위생 상태 증거처럼 쓰지 않는다.
- HTML과 JPEG는 사용자 승인된 이미지로만 제작한다. JPEG는 860px 폭, 주제별 1200~3000px 높이다.
